# `figures/` — output directory

Running `scripts/reproduce_all.py` writes here:

* `figureN.png`, `figureN.pdf`, `supp_sN_*.png|pdf` — rendered figures.
* `figureN_*.csv`, `supp_sN_*.csv` — the numeric tables behind each figure,
  saved alongside so reviewers can spot-check the underlying values.

This directory is git-ignored; only this README is tracked.
